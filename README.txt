MY WELLNESS PLAN - iPHONE WEB APP

Files:
- index.html
- manifest.json
- sw.js
- icon-192.png
- icon-512.png

What it does:
- Shows today's breakfast, fresh lunch, snack, dinner and dinner recipe
- Includes the 28-day rotating meal plan
- Includes all 14 dinner recipes
- Includes cycling / Pilates / walking schedule
- Includes four weekly mindset themes and a 15-minute practice
- Stores weight history and daily completion checks on the device using local storage
- Works as a Progressive Web App when hosted over HTTPS
- Can be added to an iPhone Home Screen from Safari

Important:
Data is stored only in that browser/device. Clearing Safari website data can erase saved progress.
